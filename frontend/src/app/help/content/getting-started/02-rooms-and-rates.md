# Room types, rooms and rates

## What it is for
Guests book a **room type**; a physical **room** is only assigned at check-in. A **rate code** gives each type its price. Without all three, nothing can be booked.

## Where to click
Setup → **Room Types**, then **Rooms**, then **Rate Codes & Calendar**. (The Rooms item in the sidebar opens the first two.)

## Fields that matter
1. Room type: **code**, **name**, **default occupancy**, **base rate**. Editing a room type afterwards is limited to the super admin.
2. Rooms: add them in bulk by number range, choosing the room type. The room number is what staff and guests see.
3. Rate code: a **code**, a **name**, and the price for each room type. Use the calendar to override a single date.

## Order matters
Room types first, rooms second (each room needs a type), rate codes last.

## You are done when
Booking → **Availability** for tonight lists your room type with a sellable count above zero, and the rate shows a price.

Trouble? See [I cannot book a room](help:common-problems/cannot-book-a-room).
